# 2026-11-04 Work Log

## Song + User N-Layer Implementation (WebAppPoliMusicV3_ASPX_F4.8_NLAYER)

Implemented the complete Song module across all 3 layers + UI for the PoliMusic Spotify-clone project.

### EntityLayer.PoliMusicV3
- **Song.cs**: Entity with IdSong, SongName, SongPath, Plays, ArtistName, AlbumTitle (view-only), FileName, IsNew
- **User.cs**: Entity with ID, UserName, Password, Email, Birthday, UserType, Photo
- **Util/Constants.cs**: USER session key, ID_USER_NORMAL=0, ID_USER_ADMIN=1
- **Util/Hash.cs**: SHA1 GeneratePasswordHash + PBKDF2 HashPassword

### DAL.PoliMusicV (references EntityLayer)
- **Song.cs**: GetAll, Search, GetById, ExistsName, Insert, Update, IncrementPlays, DeleteCascade (transaction), CountPlaylists. Uses ConfigurationManager for connection string (PoliMusicDB / BDD_PoliMusicConnectionString fallback)
- **User.cs**: Save, CheckExistUser, CheckExistEmail, Read, Update, Delete, AuthenticateUser

### BLL.PoliMusicV3 (references EntityLayer + DAL)
- **Song.cs** + **SongResult.cs**: Business logic with validations (name required, max 50 chars, plays >= 0, duplicate check), file upload handling (mp3/wav/ogg/m4a, max 25MB), Save/Delete/RegisterPlay, TotalPlays static helper
- **User.cs**: Delegates to DAL, ValidationsDuplicated

### WebAppPoliMusicV3 (references all 3 layer projects)
- **Login.aspx**: Purple-blue themed login card with PoliMusic logo
- **SignUp.aspx**: Registration form with same theme
- **Default.aspx**: Home page showing "Hola, [username]" with quick-access cards
- **Songs.aspx**: Full Spotify-like UI - sidebar, search, hero, song list (Repeater), audio player, CRUD modal. Purple-blue gradient theme (--purple: #7b3ff2, --blue: #3a6df0). Shows logged user name in topbar user-chip.
- **PlayCounter.ashx**: AJAX handler for incrementing plays without page reload
- **FileManagement.cs**: Image upload for user photos
- **Web.config**: Added connectionStrings (PoliMusicDB + BDD_PoliMusicConnectionString) and appSettings (userPhotoPath, SongUploadFolder, MaxSongFileSizeMB)
