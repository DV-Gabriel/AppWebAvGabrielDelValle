# 2026-10-28

## Módulo de canciones (TBL_SONG) implementado

Proyecto: WebAppPoliMusicV2 (ASP.NET Web Forms, .NET Framework 2.0, C# 2.0 — sin LINQ ni lambdas).

Archivos creados:
- `Entities/Song.cs` — modelo con campos privados + propiedades get/set (IdSong, SongName, SongPath, Plays) y dos propiedades de apoyo (ArtistName, AlbumTitle) que se llenan con JOIN, más FileName e IsNew.
- `DAL/Song.cs` — repositorio ADO.NET (SqlConnection/SqlCommand): GetAll, Search (nombre/artista/álbum con EXISTS), GetById, ExistsName, Insert (SCOPE_IDENTITY), Update, IncrementPlays, DeleteCascade (transacción: borra TBL_PLAYLIST_SONG, TBL_TRACKLIST, TBL_PLAYER y TBL_SONG), CountPlaylists.
- `BLL/Song.cs` — clase `Song` + clase `SongResult` (Success/Message) en el mismo archivo: validaciones (nombre obligatorio ≤50, plays ≥0, nombre duplicado), subida de archivo (mp3/wav/ogg/m4a, máx 25 MB configurable), NormalizeVirtualPath, SanitizeFileName, Delete, RegisterPlay, TotalPlays.
- `Songs.aspx` (+ .aspx.cs + .designer.cs) — UI estilo Spotify con paleta azul (fondo #060b15, acento #2e7dff), sidebar + hero + lista con Repeater + reproductor fijo abajo + modal de alta/edición + toast.
- `PlayCounter.ashx` (+ .cs) — HttpHandler que registra la reproducción por AJAX sin recargar (para que el audio no se corte).
- `Web.config` — connectionStrings `PoliMusicDB`, appSettings SongUploadFolder / MaxSongFileSizeMB, globalization utf-8, httpRuntime maxRequestLength 30720.
- `WebAppPoliMusicV2.csproj` — se agregaron todos los archivos (antes solo tenía AssemblyInfo.cs, el proyecto no compilaba nada más).

Decisiones de diseño:
- El reproductor es 100% cliente (HTML5 audio + JS); el contador se persiste vía PlayCounter.ashx → BLL → DAL.
- El modal y el toast siempre se renderizan y se muestran por CSS (`.is-open` / `.is-visible`) para no perder los valores del postback en los TextBox.
- Todos los archivos quedaron en UTF-8 con BOM (el proyecto original usa BOM) para que los acentos se compilen y rendericen bien.
- Vista previa estática de la UI generada en `.workbuddy-ai/preview/songs-preview.html` (no forma parte del proyecto).

Pendiente / notas para el usuario:
- Ajustar `Data Source` de la cadena de conexión según su instancia SQL (localhost o .\SQLEXPRESS).
- Solo existe `SongFiles/bensound-adventure.mp3`; las otras 4 canciones del script dan 404 de audio.
- El módulo de playlists del sidebar es decorativo (se conectará después).
