# 2026-10-15 Work Log

## PoliMusic - ASP Classic Spotify Clone (Blue Theme)

Built a complete ASP Classic web application (Spotify clone with blue theme) for the webapppolimusicv1_asp project.

### What was built:
- **login.asp** - Login page with session management (Session vars: username, userType, userId, userPhoto)
- **index.asp** - Main page with welcome message, Song List table, audio playback, admin CRUD buttons
- **logout.asp** - Session.Abandon + redirect to login
- **addSong.asp** - Admin only: INSERT into TBL_SONG
- **editSong.asp** - Admin only: UPDATE TBL_SONG by ID
- **deleteSong.asp** - Admin only: confirmation + DELETE from TBL_SONG
- **includes/db.asp** - ADO connection (SQLOLEDB, Windows Auth, BDD_PoliMusic DB)
- **includes/auth.asp** - RequireLogin(), IsAdmin(), RequireAdmin() helpers
- **css/style.css** - Blue Spotify-like dark theme CSS

### Database:
- SQL Server database: BDD_PoliMusic (script in BDD_PoliMusic (1).sql)
- Tables used: TBL_USER (login + roles), TBL_SONG (CRUD target)
- USER_TYPE: 0 = normal user, 1 = admin
- Connection string adapted from .NET format to ADO/SQLOLEDB provider
